# 项目数据源与采集元数据清单 (Data Sources & Metadata)

更新时间: 2026-11-17
研究区域: 武汉市江南两区及汉阳片区（**武昌区 420106、青山区 420107、汉阳区 420105**）

---

## 一、核心数据集溯源明细

### 1. 行政区划边界数据 (00_admin)
* **数据来源**: 阿里云 DataV.GeoAtlas / 民政部全国行政区划代码
* **几何类型**: MultiPolygon (面要素)
* **覆盖内容**:
  - `wuchang.geojson`: 武昌区标准行政外轮廓 (420106)
  - `qingshan.geojson`: 青山区标准行政外轮廓 (420107)
  - `hanyang.geojson`: 汉阳区标准行政外轮廓 (420105)
  - `study_area_union.geojson`: 三区联合空间总分析面

### 2. 公共服务设施 POI 数据 (01_poi)
* **数据来源**: 高德开放平台 Web 服务 API (`/v3/place/polygon`)
* **采集规模**: **25,384 条** 严格位于三区范围内的公共服务设施点
* **纠偏算法**: GCJ-02 (火星坐标) 精准非线性双迭代纠偏至 WGS84
* **7大类分布**:
  - 交通设施服务: 6,001 条
  - 政府机构及社会团体: 4,363 条
  - 科教文化服务: 4,008 条
  - 医疗保健服务: 3,894 条
  - 体育休闲服务: 3,878 条
  - 风景名胜: 1,711 条
  - 公共设施: 1,529 条

### 3. OpenStreetMap 城市道路拓扑网络 (02_road)
* **数据来源**: OpenStreetMap (OSM) / Overpass API (全球多节点容灾调度)
* **网络规模**:
  - 武昌区: 3,453 节点 / 7,492 道路段
  - 青山区: 765 节点 / 1,782 道路段
  - 汉阳区: 2,420 节点 / 5,145 道路段
  - **三区联合路网**: 6,604 节点 / 14,377 道路段
* **包含属性**: 道路等级 (`highway`)、限速 (`maxspeed`/推算时速)、单行属性 (`oneway`)、通行时长 (`travel_time`)。

### 4. 公共交通系统网络 (02_road/transit)
* **数据来源**: 武汉市公共交通与轨道交通开放数据集 (湖北省原始数据提取)
* **设施规模**:
  - **公交站点**: 884 个去重公交站 (汉阳 387 个、武昌 309 个、青山 188 个)
  - **地铁站点**: 90 个去重地铁站 (武昌 47 个、汉阳 32 个、青山 11 个)
  - **公交线路**: 558 条穿行三区公交线路 (已裁剪)
  - **地铁线路**: 28 条核心轨道线路 (2号线、4号线、5号线、6号线、7号线、8号线、11号线等)
* **深度分析产出**:
  - `transit_service_buffers.gpkg`: 公交 500m 步行服务区与地铁 800m TOD 服务区多边形图层
  - `district_transit_metrics.csv`: 各区公交/地铁站点密度、线网密度与空间服务覆盖率统计表
  - `metro_bus_transfer_analysis.csv`: 全域 90 个地铁站点周边 300m 公交接驳与换乘枢纽等级评定表

### 5. 人口与土地利用辅助分析格网 (04_stats)
* **数据来源**:
  - **WorldPop 2020**: 100m 分辨率全球人口与结构格网
  - **CLCD 2024**: 武汉大学黄昕教授团队 30m 中国年度土地覆盖数据集
* **提取指标与衍生分析成果**:
  - `raster/pop_total_2020.tif`: 三区格网总人口 (估算约 2,864,637 人)
  - `raster/pop_elderly_total_2020.tif`: 65岁以上老年总人口 (约 130,986 人，老龄化率约 4.57%)
  - `raster/clcd_landcover_2024.tif`: 30m 高精度土地覆被分类栅格
  - `population_zonal_statistics.csv`: 三区分区人口规模、密度、老龄化率与老龄性别比统计表
  - `landcover_zonal_statistics.csv`: 三区 9 大地类面积与比例、建设用地率与生态空间占比统计表
  - `transit_population_coverage_analysis.csv`: 公共交通（地铁800m/公交500m）对常住与老龄人口覆盖效能空间叠合交叉分析表

### 6. 行政区划参考数据 (00_admin/ref)
* **数据来源**: 全国省市区三级坐标边界开源数据 (AreaCity-JsSpider-StatsGov)
* **轻量化与工程提炼**:
  - 原 166.89MB 全国大文件 `ok_geo.csv` 包含 99.9% 冗余省市数据，**已从本项目工程目录中彻底剔除**，为项目直接减负 166MB；
  - `wuhan_districts_ref.geojson`: 从源数据中提炼的武汉市 13 个区县全域标准矢量多边形边界图层（仅 361KB），可用作宏观市域区位底图；
  - `wuhan_admin_reference.csv`: 清洗提取的武汉市区级行政区划代码、名称与中心坐标专表；
  - `hubei_admin_reference.csv`: 湖北省地级行政区划结构参考表。
