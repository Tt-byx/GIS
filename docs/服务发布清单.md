## 4. 渲染质量已知问题（需 R2 处理）

导出的 PNG 为 256×256 时仅 **433 字节**、800×600 时仅 **845 字节**，属纯色空白图。原因：

1. 图层元数据里 `defaultVisibility: false` —— 所有图层默认隐藏；
2. 图层 `extent` 为 `{xmin:0, ymin:0, xmax:0, ymax:0}` —— IGServer 未取到图层范围；
3. 因此 `export` 无论 bbox 怎么给都出白图。

> 归属：**R2 的 T-015（符号库与地图文档）** —— 需要在 MapGIS Desktop 里设置图层可见性、计算图层范围、配置符号后重新保存 `.mapx` 并重新发布。
> R6 侧已确认"服务本身发布正确、REST 路由可达"，渲染空属于地图文档内容问题，不重复发布。
