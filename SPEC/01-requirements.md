## 1. 编号与优先级规则

| 项 | 规则 |
|---|---|
| 功能需求 | `FR-M<模块号>-<两位序号>`，如 `FR-M3-03`。**编号分配后 MUST NOT 复用、MUST NOT 改号。** |
| 用户故事 | `US-<两位序号>` |
| 验收标准 | `AC-<FR编号>-<序号>`，如 `AC-M3-03-2` |
| 范围外 | `OOS-<两位序号>` |
| 优先级 | 仅 `P0` / `P1` / `P2` 三值，**MUST NOT 使用"高/中/低"或其他表述** |

**优先级定义（唯一版本）**

| 值 | 定义 | 处置 |
|---|---|---|
| `P0` | 缺此功能则系统不成立 | MUST 实现，MUST 通过全部 AC |
| `P1` | 缺此功能则评分明显受损 | SHOULD 实现；时间不足时由项目经理书面决定裁剪 |
| `P2` | 加分项 | MAY 实现；未排期时 MUST NOT 实现（避免占用 P0 资源） |

### 4.1 M1 地图基础操作（P0）

#### FR-M1-01 地图加载与初始化

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M1 |
| 用户故事 | US-01 |
| 依赖 | API-08；IGServer 地图服务已发布 |
| 关联任务 | T-040, T-041 |

**输入**
- `none` : — , 页面加载自动触发

**处理规则**
1. 调用 `GET /api/v1/health`，若 `components.igs != "UP"`，显示错误态并**停止后续步骤**。
2. 创建 Leaflet 地图实例，容器 `#map`，`crs` 使用 IGServer 地图文档声明的坐标系。
3. 设置初始中心与缩放级别，使三区外接矩形完整可见。
4. 加载 MapGIS 地图文档图层（图层名取自 `config/index.js` 的 `MAP_DOC_NAME`）。
5. 加载五类设施图层，默认全部可见。
6. 地图 `ready` 后广播事件 `map:ready`。

**输出**
- 可交互地图视图；事件 `map:ready`

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M1-01-1` | IGServer 正常 | 打开页面 | 5 秒内 `map:ready` 触发一次 |
| `AC-M1-01-2` | IGServer 正常 | 打开页面 | 三区边界完整落在地图视口内 |
| `AC-M1-01-3` | IGServer 停止 | 打开页面 | 显示"地图服务连接失败"文案，且不抛未捕获异常 |
| `AC-M1-01-4` | IGServer 正常 | 打开页面 | 浏览器 console 中无 `error` 级别输出 |

**禁止事项**
- MUST NOT 在页面中硬编码 IP/端口，MUST 从 `config/index.js` 读取。
- MUST NOT 把地图实例放入 Vue `ref`/`reactive`，MUST 用 `markRaw`。
- MUST NOT 在 `health` 失败时仍尝试加载图层。

#### FR-M1-02 缩放与平移

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M1 |
| 用户故事 | US-02 |
| 依赖 | FR-M1-01 |
| 关联任务 | T-041 |

**输入**
- `action` : enum{`zoomIn`,`zoomOut`,`reset`,`prevView`,`pan`}, 无默认值 — 视图操作类型

**处理规则**
1. `zoomIn` / `zoomOut`：按 1 级步长调整，边界限制在 `[MIN_ZOOM, MAX_ZOOM]`。
2. `reset`：恢复到初始中心与缩放级别。
3. `prevView`：回到上一个视图状态，历史栈深度上限 10。
4. `pan`：拖拽平移，结束时压入历史栈。
5. `MIN_ZOOM = 8`，`MAX_ZOOM = 18`，越界时静默钳制，不报错。

**输出**
- 视图变化；事件 `map:viewchange`（携带 `center`,`zoom`）

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M1-02-1` | 当前 zoom=10 | 连续 `zoomOut` 5 次 | zoom 停在 8，不出现异常 |
| `AC-M1-02-2` | 当前 zoom=10 | 连续 `zoomIn` 12 次 | zoom 停在 18 |
| `AC-M1-02-3` | 平移过 3 次 | 点击"上一视图" | 依次回退，第 4 次点击无变化且不报错 |

**禁止事项**
- MUST NOT 在缩放后自动重置图层可见性。
- MUST NOT 使用浏览器原生滚动条实现平移。

#### FR-M1-04 量算工具

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M1 |
| 用户故事 | US-02 |
| 依赖 | FR-M1-01 |
| 关联任务 | T-041 |

**输入**
- `mode` : enum{`distance`,`area`} — 量算类型
- `unit` : enum{`m`,`km`,`m2`,`ha`} — 输出单位

**处理规则**
1. `distance`：左键逐点添加折线顶点，双击结束；实时显示累计长度。
2. `area`：左键逐点添加多边形顶点，双击闭合；实时显示面积。
3. 单位换算：`1 km = 1000 m`；`1 ha = 10000 m²`。
4. 结束绘制后，结果以浮层显示，保留 2 位小数。
5. 调用 `clearMeasure()` 时移除图形与浮层。
6. 量算基于 **CGCS2000 经纬度**，MUST 使用 `Turf.js` 的 `length` / `area` 计算，MUST NOT 用平面欧氏距离。

**输出**
- 量算图形 + 数值浮层

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M1-04-1` | 量算模式=距离 | 绘制两点（相距约 1km） | 结果显示 0.99–1.01 km |
| `AC-M1-04-2` | 量算模式=面积 | 绘制约 1km×1km 矩形 | 结果显示 99–101 ha |
| `AC-M1-04-3` | 已绘制图形 | 调用 `clearMeasure()` | 图形与浮层均消失 |

**禁止事项**
- MUST NOT 用屏幕像素距离换算实际距离。
- MUST NOT 在未双击结束时给出最终结果。

#### FR-M1-05 图层控制

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M1 |
| 用户故事 | US-02 |
| 依赖 | FR-M1-01 |
| 关联任务 | T-042 |

**输入**
- `layerId` : string — 图层标识，取值见 `config/index.js` 的 `LAYERS`
- `visible` : boolean
- `opacity` : number, `0..1`, 默认 `1`

**处理规则**
1. 图层树按三组渲染：`底图` / `设施` / `分析结果`。
2. 五类设施 MUST 各自独立可切换，MUST NOT 合并为一个开关。
3. 透明度作用到 Leaflet layer 的 `setOpacity`；底图图层 MUST NOT 支持透明度调整。
4. 图层顺序调整后，MUST 调用 `bringToFront`/`bringToBack` 使渲染顺序与树顺序一致。
5. 图例 MUST 随图层显隐同步变化：隐藏某类设施时，图例对应项置灰。

**输出**
- 图层可见性/透明度变化；事件 `layer:visibilitychange`

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M1-05-1` | 五类图层均可见 | 关闭"教育" | 教育图层不可见，其余四类可见不变 |
| `AC-M1-05-2` | 教育图层已关闭 | 查看图例 | 教育项为置灰状态 |
| `AC-M1-05-3` | 设施图层可见 | 设置 opacity=0.5 | 图层透明度为 0.5，底图不受影响 |

**禁止事项**
- MUST NOT 通过删除图层实现隐藏（MUST 用 `visible` 控制）。
- MUST NOT 允许底图透明度被修改。

#### FR-M1-06 底图切换

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M1 |
| 用户故事 | US-02 |
| 依赖 | FR-M1-01；天地图 Key 已配置在后端 |
| 关联任务 | T-041 |

**输入**
- `basemap` : enum{`mapgis`,`tianditu_vec`,`tianditu_img`}, 默认 `mapgis`

**处理规则**
1. `mapgis`：MapGIS 发布的本地瓦片服务。
2. `tianditu_vec` / `tianditu_img`：天地图 WMTS（经 IGServer 聚合或直连，取值见 `config`）。
3. 切换时 MUST 先移除旧底图再添加新底图，底图图层数量恒定 ≤ 1。
4. **切换后设施图层坐标 MUST NOT 偏移**（偏移 < 10 米）。
5. 界面 MUST 显示当前底图来源标注：`底图来源：天地图` 或 `底图来源：MapGIS`。
6. 天地图 Key MUST 从后端获取（`GET /api/v1/meta/dict` 返回的 `tiandituToken` 字段），MUST NOT 硬编码在前端。

**输出**
- 底图替换；事件 `basemap:change`

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M1-06-1` | 底图=mapgis | 切换到 tianditu_vec | 3 秒内新底图可见，旧底图移除 |
| `AC-M1-06-2` | 任一底图 | 记录某设施屏幕坐标，切换底图后对比 | 两坐标偏差 < 10 米对应像素 |
| `AC-M1-06-3` | 任一底图 | 查看界面 | 存在底图来源标注文本 |

**禁止事项**
- MUST NOT 引入 Google / Apple / Bing 海外版 / OSM 直连瓦片 / Mapbox 底图（`G-09`）。
- MUST NOT 叠加多个底图。
- MUST NOT 在前端 JS 中出现天地图 Key 明文。

### 4.2 M2 设施查询与定位（P0）

#### FR-M2-01 属性查询

| 字段 | 值 |
|---|---|
| 优先级 | P0 |
| 模块 | M2 |
| 用户故事 | US-03 |
| 依赖 | API-01, API-02 |
| 关联任务 | T-043 |

**输入**
- `categoryL1` : string, 见 02 字典, 默认空 — 大类筛选
- `categoryL2` : string, 见 02 字典, 默认空 — 中类筛选
- `districtCode` : string, `420111|420106|420105`, 默认空
- `streetCode` : string, 见字典, 默认空
- `keyword` : string, 长度 `0..50`, 默认空 — 名称模糊匹配
- `page` : int, `>=1`, 默认 `1`
- `size` : int, `1..200`, 默认 `20`

**处理规则**
1. 全部条件以 AND 组合，空值条件 MUST 忽略。
2. `keyword` 使用 **包含匹配（LIKE %kw%）**，MUST NOT 使用前缀或全文检索。
3. 结果按 `facCode` 升序返回。
4. 结果总数 > 0 时，点击列表项 MUST 触发 `flyToFeature(facCode)`。
5. 结果为空时 MUST 显示空状态组件，文案固定为：`未找到符合条件的设施，请放宽筛选条件`。

**输出**
- 分页列表；事件 `query:result`

**验收标准**

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-M2-01-1` | 数据已入库 | `categoryL1=MED` 查询 | 返回记录 `categoryL1` 全为 `MED` |
| `AC-M2-01-2` | 数据已入库 | `keyword=社区` 查询 | 所有返回记录 `name` 含"社区" |
| `AC-M2-01-3` | 数据已入库 | 查询无结果条件 | 响应 `total=0`，界面显示指定空状态文案 |
| `AC-M2-01-4` | 有查询结果 | 点击列表第 1 项 | 地图定位到该设施，缩放级别 = 16 |

**禁止事项**
- MUST NOT 在前端做二次过滤（过滤逻辑 MUST 在后端/IGServer）。
- MUST NOT 返回 `fid` 字段。
- MUST NOT 分页参数缺省时返回全部数据。
