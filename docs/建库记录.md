## 3. `ROAD` 字段契约与导入映射

### 3.1 字段（与 `SPEC/02` §3.4 一致）

`ROAD_ID`（整型，唯一）、`ROAD_NAME`（字符串）、`ROAD_CLASS`（字符串，四值）、`LENGTH_M`（双精度，米）、`WALK_SPEED`（双精度，米/分钟）、`DRIVE_SPEED`（双精度，km/h）、`ONE_WAY`（整型，0/1）。

### 3.2 源数据与导入

- 源：OSM 路网（`data/road/road_clean.gpkg`），经 GeoPandas 重投影为 EPSG:4490 的 `temp/import/road_edges_cgcs2000.gpkg`（图层 `ROAD`，14377 条），再导入 GDB 的 `ROAD` 要素类。
- 导入映射与生成规则见 `temp/import/README.md`：`ROAD_ID` 按源顺序 `1..N`；`highway → ROAD_CLASS` 按主/次/支/步行四级映射；`LENGTH_M` 取源米制长度；`WALK_SPEED` 常量 **75**；`DRIVE_SPEED` 按等级赋值（主干道 40、次干道 30、支路 20）；`ONE_WAY` 取源 `oneway`。
- 编码：UTF-8；中文道路名无乱码。

### 3.3 属性核验（2026-11-27）

用 MapGIS 属性视图「另存为文本」导出全部 14377 条（`temp/road_attr_export.txt`，8 字段），再用 `temp/analyze_road.py` 统计：

| 检查项 | 结果 |
|---|---|
| 记录数 | 14377（导出记录数与图元数一致） |
| `ROAD_ID` | 1–14377，唯一，重复 0 |
| `WALK_SPEED` | 非空 14377，空/非法 0，**≤0 的 0 条，最小值 75，最大值 75** |
| `DRIVE_SPEED` | 40→2374、30→2469、20→9534，与等级一一对应 |
| `ROAD_CLASS` | 主干道 2374、次干道 2469、支路 9534、步行道 0 |
| `ONE_WAY` | 0（双向）8632、1（单行）5745 |
| `ROAD_NAME` | 空值 832 条（允许） |

> 结论：`ROAD.WALK_SPEED` 全部 > 0，满足 T-017 DoD 第 3 条。

## 5. 路网拓扑检查（T-017）

### 5.1 检查方法与参数

| 项 | 值 |
|---|---|
| 工具 | MapGIS Desktop 10.10.10：`通用编辑 → 拓扑检查` |
| 图层 A | `ROAD`（线） |
| 拓扑规则 | **（线）不能有悬挂点**（端点必须与其他线的端点相连） |
| 容差 | `0.00000001`（度） |
| 结果 | 拓扑错误管理：**110 个错误**，全部为「(线)不能有悬挂点」，要素 2(ID) 均为 0 |
| 证据 | `temp/t017_dangle.te`（MapGIS 拓扑错误库，SQLite；110 行 `ERRINFOTABLE`）、`temp/t017_dangle_list.json`、`temp/t017_dangle_geo.json`、`temp/t017_dangle_table.md` |

### 5.2 判定与逐条说明口径

对 110 条错误逐条关联 `ROAD` 属性与几何（以源路网 EPSG:4490 几何、投影到 EPSG:32650 计算米制距离）：

- 110 个错误对应 **110 个不同要素**，每个要素**只有 1 个悬挂端点**；**没有**「两端都悬挂」的孤立路段 → 路网不存在脱离主网的碎片，悬挂点均为**支状尽端**，另一端与主网相连。
- 按悬挂端点距研究区边界（三区并集）的距离分档：
  - **A 区界裁切（≤30 m）：5 条** —— 道路在区界处被裁断，端点落在研究区边界；
  - **B 近边界尽端（30–200 m）：19 条** —— 贴近区界、可能由裁切缓冲造成；
  - **C 研究区内部尽端（>200 m）：86 条** —— 尽端路/匝道/服务通道末端（另一端与主网相连），不构成断网。
- 按等级：主干道 83、次干道 20、支路 7。主干道中的悬挂点多为 `primary_link` 类匝道/引道，映射为「主干道」后在汇入处终结。

> 结论：悬挂点 **110 个，已逐条说明**（见附录 A），满足 T-017 DoD 第 1 条的「或已逐一说明」。若后续要求严格 0 悬挂，需要业务方确认是否删除/延伸这 110 条尽端支路——本任务不擅自改几何。

### 5.3 复现步骤

1. 打开 `data/mapdoc/wh_facility.mapx`（或 GDB 的 `ROAD` 图层），把 `ROAD` 设为当前层。
2. `通用编辑 → 拓扑检查`，图层 A 选 `ROAD`，规则选「(线)不能有悬挂点」，容差 `0.00000001`，执行。
3. 拓扑错误管理显示 110 个错误；「导出」为 `.te` 后用 `temp/extract_dangle.py`、`temp/verify_dangle_geo.py` 生成逐条说明。
