## 4. 渲染质量已知问题（需 R2 处理）

导出的 PNG 为 256×256 时仅 **433 字节**、800×600 时仅 **845 字节**，属纯色空白图。原因：

1. 图层元数据里 `defaultVisibility: false` —— 所有图层默认隐藏；
2. 图层 `extent` 为 `{xmin:0, ymin:0, xmax:0, ymax:0}` —— IGServer 未取到图层范围；
3. 因此 `export` 无论 bbox 怎么给都出白图。

> 归属：**R2 的 T-015（符号库与地图文档）** —— 需要在 MapGIS Desktop 里设置图层可见性、计算图层范围、配置符号后重新保存 `.mapx` 并重新发布。
> R6 侧已确认"服务本身发布正确、REST 路由可达"，渲染空属于地图文档内容问题，不重复发布。

## 9. 复现命令

```bash
# 服务文档列表
curl http://localhost:6163/igs/rest/mrcs/docs

# 地图文档元信息
curl http://localhost:6163/igs/rest/mrcs/docs/wh_facility_main

# 5 个图层元数据
for i in 0 1 2 3 4; do
  curl "http://localhost:6163/igs/rest/services/wh_facility_main/MapServer/$i?f=json"
done

# 出图（PNG）
curl -o map.png "http://localhost:6163/igs/rest/services/wh_facility_main/MapServer/export?bbox=114.0,30.3,114.8,30.8&size=800,600&format=png"

# 瓦片缓存信息（当前全 0）
curl http://localhost:6163/igs/rest/mrms/info/wh_facility_main
```
